# Security policy

ResearchAtlas reads local agent transcripts, which can contain credentials, private paths and research data. It
writes only inside the atlas home, and the Copilot uploader uses your existing SSH setup without storing secrets.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/benedictdavon/ResearchAtlas/security/advisories/new) rather
than in a public issue. Include the affected version, steps to reproduce and the impact. Don't attach real
transcripts. You can expect an initial response within a week.

## Supported versions

Security fixes go into the latest release.
